# Order Data Analysis with Python

## Project Overview

This project focuses on exploring and preparing order data using Python. It includes an analysis notebook, the original dataset, a cleaned dataset, and a city-level summary.

The project demonstrates a basic data analysis workflow, from working with raw data to preparing structured data for further analysis.

## Tools & Technologies

- Python
- Jupyter Notebook
- pandas
- CSV data processing

## Project Structure

| File | Description |
|---|---|
| `Proiect.ipynb` | Jupyter Notebook containing the analysis and code |
| `comenzi.csv` | Original order dataset |
| `comenzi_curat.csv` | Cleaned order dataset |
| `rezumat_orase.csv` | Summary of data grouped by city |

## Workflow

1. Load and inspect the original order data.
2. Explore the dataset and identify data quality issues.
3. Clean and prepare the data.
4. Export the cleaned dataset to a CSV file.
5. Prepare a city-level summary for further analysis.

## How to Run

1. Clone or download this repository.
2. Make sure Python and Jupyter Notebook are installed.
3. Install pandas:

   ```bash
   pip install pandas
   ```

4. Open `Proiect.ipynb` in Jupyter Notebook or Visual Studio Code.
5. Run the notebook cells in order.
